# 2D game
Current branch where the progress is `arch_ref`

---

Tilesets-`Libresprite`  
Tilemap -`Tiled `  
Main modules-`Pygame`,`pytmx` 

### Structure of the game  

Village map  
dungeon ground floor  
dungeon floor 1(traps)  
dungeon floor 2(traps)  
dungeon floor 3(monsters)  
dungeon floor 4(boss)  
dungeon floor 5(crop of vitality)  
village  

### Storyline

A dungeon opens in the village,villagers send a few people to raid it but they return with a disease.
The hero visits the village head, village head says "all dungeons have their own cures" and the hero raids the dungeon and clears it and finds the cure.

### Abbreviations for contributors
* d = dungeon
* f = floor

### Rules to contribution

I recommend that before you make a Pull Request you follow these or the PR might get rejected:

* Make commits with little code and a single purpose, so they're easier to understand.

* Make sure you pull before you start writing new code, so it matches the latest commit.

* Add enough comments to explain the why and how of your changes.

* Make sure to PR to a side-branch and not main.

* AI used PRs are going to be rejected as the intention of the project is to learn

* No formatting or type hinting or readability changes are accepted atm.

* The branch with current progress will be added to the top of this page.
